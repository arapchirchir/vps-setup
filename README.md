# VPS Infrastructure Playbook

This repository documents a **production-ready VPS setup** for Ubuntu servers.

## What's covered

- Secure access and users
- SSH hardening
- Firewall rules
- Nginx multi-domain hosting
- PHP 8.3 (FPM)
- PostgreSQL
- Let’s Encrypt SSL
- Security baselines
- Ongoing operations

All steps are **tested and proven in real deployments**.

> Assumes Ubuntu 22.04 / 24.04 LTS
