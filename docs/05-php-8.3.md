# 05 – PHP 8.3 Setup (PHP-FPM)

This section installs **PHP 8.3** with PHP-FPM and common extensions, and prepares it for use with Nginx.

---

## 1) Add PHP repository

```bash
sudo add-apt-repository ppa:ondrej/php -y
sudo apt update
````

---

## 2) Install PHP 8.3 and extensions

```bash
sudo apt install -y \
  php8.3 \
  php8.3-cli \
  php8.3-fpm \
  php8.3-curl \
  php8.3-mbstring \
  php8.3-xml \
  php8.3-zip \
  php8.3-pgsql
```

---

## 3) Enable and start PHP-FPM

```bash
sudo systemctl enable php8.3-fpm
sudo systemctl start php8.3-fpm
sudo systemctl status php8.3-fpm --no-pager -l
```

---

## 4) Verify PHP installation

```bash
php -v
```

Expected output should show **PHP 8.3.x**.

---

## 5) PHP-FPM socket reference (important)

Nginx must use this socket:

```text
/run/php/php8.3-fpm.sock
```

This is already referenced in your Nginx server blocks.

---

## 6) PHP-FPM hardening (recommended)

Edit the PHP-FPM config:

```bash
sudo nano /etc/php/8.3/fpm/php.ini
```

Set or confirm these values:

```ini
expose_php = Off
cgi.fix_pathinfo = 0
session.cookie_httponly = 1
session.cookie_secure = 1
disable_functions = exec,passthru,shell_exec,system,proc_open,popen
```

Restart PHP-FPM:

```bash
sudo systemctl restart php8.3-fpm
```

> If your site is not HTTPS yet, set `session.cookie_secure = 0` and turn it back on after HTTPS.

---

## Troubleshooting

### PHP files downloading instead of executing

- Confirm `php8.3-fpm` is running
- Confirm Nginx `fastcgi_pass` points to the correct socket

### Check logs

```bash
sudo journalctl -u php8.3-fpm --no-pager -n 200
```
